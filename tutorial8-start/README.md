# Foyer — tutorial 8, starting point

The tree Duet Tutorial 8 opens: Tutorial 6's finished tree — the whole app,
its checks as one workflow and the mutation drill's table — plus one
deliberately failing test, the tutorial's closing exercise. Tutorials 7, 8
and 9 all open this same tree, so you can take them in any order. The
tutorial text lives at <https://docs.modaal.dev/tutorials/duet-08-localization>; this
README is a pointer, not a copy.

```sh
tools/duet verify
```

The command above is green before the first edit, apart from the one
deliberately failing test the tutorial's closing exercise asks you to make
pass (`Tutorial8ExerciseRecordingsUnchangedTest`).
